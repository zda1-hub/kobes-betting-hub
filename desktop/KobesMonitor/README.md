# Kobe's Monitor

Native macOS menu-bar wrapper for the private Kobe's Betting Hub analytics dashboard.

- Click the yellow chart icon labeled **KBH** in the menu bar.
- Press **Control–Option–K** from anywhere to show or hide it.
- Sign in with the authorized Discord account inside the app.
- Use **Refresh** for current production data or **Open in Browser** when needed.

Build locally with `zsh build.sh`. The resulting app is placed in `build/Kobe's Monitor.app`.
