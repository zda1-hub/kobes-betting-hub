# KBH X growth loop — October 19, 2026 MST

## What ships now

- Publish each approved Free Pick before the game with the exact wager, odds, useful evidence, and one tracked link to the Free Pick page. Never describe a pending pick as a win.
- Publish the verified final result as its own X post. When it fits X's length limit, include a link to the original pregame post so a reader can check the claim. If the exact wager and final outcome use the space, publish those core facts without the optional link.
- Use one real behind-the-pick story per week. It can explain why a line was chosen, what changed, and what the result taught us. Label any hypothetical scenario. Do not invent member payouts, screenshots, quotes, scarcity, or guaranteed profit.
- Keep the primary CTA consistent: view the current Free Pick and decide whether the VIP community is useful. The existing pregame post uses the tracked `/free-pick?utm_source=kobe_x` path. Result posts point back to their original post when space allows.
