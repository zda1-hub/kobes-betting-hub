# Next improvements for review — calculator utility

October22,2026 MST. Research-only proposals; no further public changes deployed.

## Evidence and scope

Web search samples checked: “basketball per36 calculator minutes seconds mm:ss” and “basketball combined shooting percentage average percentages calculator”. These are discovery queries, not localized Google rank measurements, volume estimates or proof that a named page ranks above KBH.

Opened All Over Tools’ own shooting-percentage page. It offers a made/attempted calculation, arithmetic details and plain-text copy/download actions. This confirms an available reader-task format, not that its implementation or math was independently tested.
Source: https://allovertools.com/calculators/sports-calculators/basketball-shooting-percentage-calculator/

## 1. Reusable calculation summaries

Proposal: add Copy result beside each existing calculator’s output, with a visible text fallback if clipboard access fails. Keep it a deliberate reader action. Include statistic, entered totals/denominators, reporting window, formulas, rounding note and educational limitation. No inputs in URLs, automatic sharing, analytics payloads, storage or server calls.

Example output:
“Points — invented four-appearance example. A:48 total,4 appearances,48 minutes;12/game,1/minute,36/per36. B:72 total,4 appearances,120 minutes;18/game,0.6/minute,21.6/per36. Describes these records; not a prediction.”

Why: readers can keep an auditable explanation instead of transcribing isolated numbers. This is a utility hypothesis, not a measured SEO benefit. Acceptance: keyboard/mobile action, clipboard failure fallback, consistent refreshed/reset/error states, input values never transmitted automatically.

## 2. Make combined percentages explorable inside the existing FAQ

Current gap: KBH explains70% unweighted vs83.3% pooled with original1/2 and9/10 records, but the mean/median calculator cannot combine makes and attempts. Add a small two-group comparison only within that FAQ, not a duplicate article or broad shooting dashboard.

Show each group’s makes/attempts and percentage, the unweighted mean, and the combined numerator/denominator. Label all examples invented. Require matching shot definitions and non-overlapping records. Reject negative/fractional counts, makes above attempts and invalid denominators. Make zero-attempt groups explicitly unavailable for a group mean; never silently turn undefined rates into zero. Keep original static examples as fallback.

Differentiation from the sampled single-pair tools: explain why the two averages answer different questions using the same records. No player forecasts, league benchmarks, betting recommendations or copied competitor prose.
