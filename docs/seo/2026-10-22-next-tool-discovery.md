# Next improvements for review — make existing tools easier to find

October22,2026 MST. Research-only proposals; no public changes implemented here.

## Evidence

Search sample: “weighted average percentages calculator combining groups attempts sample size”. NumberBench’s own average-percentage page exposes calculator input fields, formula/method sections and category navigation. It accepts percentages and optional weights; KBH’s raw-count comparison already serves a distinct educational task, so another near-duplicate percentage page is not justified by this sample.
Source opened: https://numberbench.com/average-percentage-calculator

Current-source finding: the KBH learning hub links to the two article starts but does not give direct labeled entry points to their three interactive tools. The mean article now has its own Combine percentages contents link; this release does not change the hub body.

## Priority1: direct calculator links within the existing statistics card

Preserve the cream card and its two guide descriptions. Add a compact “Try a calculator” group with these ordinary crawlable links:
- Mean and median → /education/mean-versus-median#try-title
- Combine two shooting percentages → /education/mean-versus-median#try-percentages
- Per-game, per-minute and per36 → /education/per-game-versus-per-minute#compare-records

Readers looking for a tool can reach its inputs directly; readers wanting the explanation retain the full-guide links. No new index page, duplicate article or claim of additional keyword demand. Verify heading clearance, mobile wrapping, keyboard focus, fallback content and all three anchor arrivals before publishing.

Google recommends descriptive crawlable links to aid discovery and understanding. This proposal is a navigation hypothesis, not a guarantee of higher ranking.
Source opened: https://developers.google.com/search/docs/crawling-indexing/links-crawlable

## Priority2: measure discovery before adding more features

Use Search Console page/query data once the pages have been crawled. Separate branded queries from mean/median, combined/weighted percentage and per-game/per36 intent. Record the data-through date and compare matched windows; do not infer improvement from deployment alone. Then review whether titles/descriptions accurately match actual impressions and reader intent. Google chooses snippets dynamically, sometimes using the description; a metadata edit cannot force the displayed snippet.
Source opened: https://developers.google.com/search/docs/appearance/snippet

No localized rank, current indexing status, search volume or traffic lift was verified by these search samples. No paid research, outreach or automation activated. Recommendation: improve access to the tools already built and evaluate real discovery data before expanding to more calculators.
